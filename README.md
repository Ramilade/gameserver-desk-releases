# GameServer Desk – downloads

Desktop app for Windows to monitor and manage game servers on Proxmox (VMs/LXC) or on your own PC: status, players,
kick/ban, restarts, Steam updates, backups, mods and a phone companion.

**Download:** open [Releases](https://github.com/Ramilade/gameserver-desk-releases/releases/latest) and run
`GameServerDesk-Setup-<version>.exe`. Installed apps update themselves from here.

This repository only hosts the installers and the signed update feed (`latest.json`); the source code is private.
